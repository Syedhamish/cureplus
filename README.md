# 🏥 CurePlus – Smart Healthcare Platform

CurePlus is a smart healthcare platform designed to simplify access to healthcare services by connecting patients with hospitals, doctors, and essential medical resources through a user-friendly digital interface.

## 📌 Project Overview

CurePlus aims to bridge the gap between patients and healthcare providers by improving access to medical information, hospital resources, and emergency healthcare services.

The platform focuses on reducing unnecessary hospital visits, waiting times, and difficulties in finding appropriate medical facilities.

## 🎯 Objectives

- Simplify access to healthcare services.
- Improve communication between patients and hospitals.
- Reduce delays in accessing medical facilities.
- Provide a centralized healthcare platform.
- Improve emergency healthcare accessibility.

## ✨ Key Features & Proposed Capabilities

- 🏥 Hospital discovery and information
- 👨‍⚕️ Doctor availability and scheduling
- 🛏️ Hospital bed availability tracking
- 🫁 Oxygen and medical resource availability
- 🚑 Emergency SOS and ambulance support
- 📍 Location-based hospital discovery
- 🔐 Patient and hospital login
- 📊 Healthcare dashboard
- 📱 Responsive and user-friendly interface

- `src/main.tsx` – Application entry point

- `package.json` – Project dependencies
- `vite.config.ts` – Vite configuration
- `tsconfig.json` – TypeScript configuration

## 🚀 Installation and Setup

### 1. Clone the repository

    git clone https://github.com/Syedhamish/cureplus.git

### 2. Navigate to the project directory

    cd cureplus

### 3. Install dependencies

    npm install

### 4. Start the development server

    npm run dev

### 5. Build for production

    npm run build
